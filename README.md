# NB破甲桌面演示版

一个更直观的 NB破甲桌面入口。先体验界面与操作流程，再了解正式服务。

## 界面包含

- 总览：快速了解桌面端
- AI 工作台：体验对话输入、示例提示词与模型选择
- 模型目录：按场景浏览功能分类
- 开通指引与本地界面设置

> 当前版本仅供界面演示，不连接真实 API，也不会上传对话输入。点击发送会显示开通指引。

## 获取正式服务

可用模型、使用规则和开通方式以 [NB破甲 TG 群](https://t.me/HaoNB_6666) 内的最新公告为准。

请在本仓库的 **Releases** 页面下载 Windows x64 便携版 EXE。双击即可运行，无需安装。
